# LOGIC BOMB

Небольшой LAN-эксперимент: планшетный интерфейс рассылает звонок телефонам, на которых открыта страница. Тишина в конце исходного аудио слегка подрезается, после чего фрагмент заранее собирается в один непрерывный звонок длительностью около 12 секунд.

## Запуск

Зависимости устанавливать не требуется. На Windows запустите:

```powershell
.\start.cmd
```

Скрипт использует обычный Node.js 20+ или встроенный runtime Codex, если Node.js не добавлен в PATH.

Сервер напечатает адрес вида `http://192.168.1.10:4173`. Откройте именно этот адрес на каждом телефоне в той же Wi-Fi-сети.

Оставьте вкладку открытой. Первое обычное касание в любом месте страницы бесшумно разблокирует звук — отдельной кнопки активации нет, и при загрузке страницы аудио не запускается. Чтобы позвонить, проведите пальцем или мышью сверху вниз по пяти целям. Модуль `LOGIC BOMB` становится доступен только после выделения всех строк. Нажатие на него запускает примерно 2,2-секундную анимацию взлома, затем отправляет смешанный двухдорожечный звонок, glitch-анимацию и, на поддерживаемом Android, вибрацию подключённым телефонам. У отправителя звук и входящий экран не воспроизводятся, а панель становится неактивной до конца звонка.

Отправлять звонок могут только iPad и устройства с полноразмерным экраном: desktop или laptop. Такие устройства не принимают чужие звонки. На телефонах управляющая панель и надписи скрыты; телефон работает только как получатель и не показывает отдельного предупреждения об этом.

Касания во время входящего звонка отображаются как удары по экрану, но не сбрасывают звук. При блокировке экрана или уходе браузера в фон звук на этом телефоне прекращается локально.

## PWA

Добавлены web app manifest, Service Worker, standalone-режим и отдельные иконки Dokkaebi для iOS и Android. На iPhone откройте страницу в Safari, выберите «Поделиться» → «На экран Домой» и включите «Открыть как веб-приложение».

Service Worker доступен браузерам только на доверенном HTTPS-адресе или на `http://localhost`. Поэтому с обычного LAN-адреса вида `http://192.168…` установка ярлыка и standalone-режим доступны, но офлайн-кэш Service Worker заработает только после публикации этого же сайта через доверенный HTTPS.

Другой порт можно указать аргументом:

```powershell
.\start.cmd 8080
```

## Ограничение iPhone

Safari и другие браузеры iPhone не предоставляют сайтам Vibration API. На iPhone событие воспроизводит присланный звук и GSAP glitch-анимацию, но настоящую вибрацию из веб-страницы запустить нельзя. iOS также требует хотя бы одно касание страницы до первого воспроизведения. Если звонок приходит уже после полной приостановки вкладки заблокированным телефоном, обычный сайт не может гарантированно разбудить браузер.

Если Windows спросит разрешение для Node.js в брандмауэре, разрешите доступ для частных сетей. Гостевая Wi-Fi-сеть с изоляцией клиентов может блокировать соединение между телефонами и компьютером.
